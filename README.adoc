= versions

Universal version manager over the command namespace; ecosystems ship an extension, not a manager.

link:https://github.com/openshellorg/versions/issues[Report Bug] |
link:https://github.com/openshellorg/versions/issues[Request Feature] |
link:https://docs.opensh.org/tools/versions/index.html[Explore the docs]

== About The Project

Part of the OpenShellOrg command-namespace work: the shell finds commands in a hierarchical, task-shaped namespace instead of searching `PATH`.
Design seed: link:https://github.com/openshellorg/project-plans/blob/main/seeds/2026-10-26%20-%20universal-version-manager.md[project-plans seed]. Concept page: link:https://docs.opensh.org/open-shell-org/concept-command-namespace.html[Command namespace and context requests].

Status: scaffold only.
